When you need to split a PDF

Sometimes you only need part of a document: one signed page from a long contract, a single month from a year of statements, one chapter of a report. Splitting lets you send exactly what's needed, and nothing you'd rather keep private.

How to write page ranges

  • A single page: 5
  • A range: 3-7 gives one file with pages 3 to 7.
  • Several separate files: 1-2,3-5,6-10 gives three PDFs.

Each range you write becomes its own PDF, and each can be downloaded separately.

Common uses

  • Sending only the relevant pages of a medical file or a legal document.
  • Breaking a large scanned batch into separate documents.
  • Making a file small enough for an upload limit by leaving out pages that aren't needed.

Need to put pages back together?

Use Merge PDF to combine the parts, in any order.

Range examples

  • Only the last page of a 12-page contract: 12
  • Each month separately from three months of bank statements, four pages a month: 1-4,5-8,9-12
  • The whole document without the cover page: 2-20 (for 20 pages)
  • Two non-adjacent pages in one file: extract each one first, 3,9, then combine them with Merge PDF.

Common problems and fixes

  • You don't know how many pages the file has: open it on your phone or computer; the page count shows at the bottom or side.
  • A range past the end of the file: if you wrote 8-15 and the file ends at page 10, fix the range and run again.
  • The file is password-locked: remove the password first with Unlock PDF.
  • You need an image of a page, not a PDF: for WhatsApp or Instagram, PDF to Image fits better.

Privacy

Splitting is a simple way not to send more than needed. If a page you do need to send has a detail you'd rather not share, like an account or ID number, black it out with Redact PDF.
