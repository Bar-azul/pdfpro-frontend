When you need to split a PDF

Sometimes you only need part of a document: one signed page from a long contract, a single month from a year of statements, one chapter of a report. Splitting lets you send exactly what's needed, and nothing you'd rather keep private.

How to write page ranges

  • A single page: 5
  • A range: 3-7 gives one file with pages 3 to 7.
  • Several separate files: 1-2,3-5,6-10 gives three PDFs.

Each range you write becomes its own PDF, and each can be downloaded separately.

Common uses

  • Sending only the relevant pages of a medical file or a legal document.
  • Breaking a large scanned batch into separate documents.
  • Making a file small enough for an upload limit by leaving out pages that aren't needed.

Need to put pages back together?

Use Merge PDF to combine the parts, in any order.
