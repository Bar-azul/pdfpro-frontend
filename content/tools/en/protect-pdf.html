When to protect a PDF

Email isn't a private channel. Messages get forwarded, sit in shared inboxes and stay in sent folders for years. If a document contains an ID number, bank details, salary or health information, a password means that anyone who ends up with the file still can't read it.

How strong is the protection?

The file is encrypted with AES-256, the same standard PDF readers use for their strongest protection. In practice, the weak point is the password, not the encryption: a short password or an obvious one, like a phone number, is much easier to guess than a random phrase.

Tips for sharing a protected PDF

  • Send the password through a different channel than the file, for example the file by email and the password by text message.
  • Don't reuse a password you use for an important account.
  • Keep an unprotected copy for yourself, or keep the password somewhere safe. There's no way to recover a forgotten one.
