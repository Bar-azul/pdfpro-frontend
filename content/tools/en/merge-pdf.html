When you need to merge PDFs

Many forms ask for a single file: a job application with a CV and certificates, a mortgage request with several months of payslips, an insurance claim with receipts and a medical report. Merging turns a pile of separate PDFs into one document, in the order the reader expects.

Getting the order right

The first file in the list becomes the first pages. Add the files, then use Move up to arrange them. If you're combining documents for an official request, follow the order the institution lists, since reviewers often check documents in that sequence.

Files that won't merge

  • Password-protected PDFs, like payslips and bank statements that open with your ID number, need the password removed first. Use Unlock PDF on each one, then merge.
  • Photos and scans that are JPG or PNG rather than PDF can be turned into a PDF with JPG to PDF, then merged.
  • Word documents can be converted with Word to PDF.

After merging

A merged file can be large, especially when it includes scans. If an upload form rejects it, run it through Compress PDF.

Combining PDFs on a phone

You can combine files from a phone too, with no app. Tap the upload area and pick several files at once: on Android long-press the first file and tick the rest, on iPhone use "Select" in the Files app. Files you received in WhatsApp or by email need to be saved to the phone first before they show up in the list.

Common problems and fixes

  • "The file is password-protected": one file in the list is locked. Remove its password and upload just that one again.
  • The order came out wrong: the first file in the list becomes the first pages. Arrange them before running, not after.
  • More than 20 files: combine in two rounds. First the first 20, then the combined file together with the rest.
  • One sideways page in the middle: merging keeps every page exactly as it was. If a page is sideways, turn it afterwards with Rotate PDF.
  • You only need some pages of a file: take them out first with Split PDF and merge only what you need.

What happens to the files

Files are combined as they are: text, links and quality don't change, and no watermark is added. Your uploads and the merged file are deleted from the server after one hour.
