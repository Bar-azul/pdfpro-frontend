Why pages come out sideways

Scanners and phone scanning apps guess which way is up, and they often guess wrong: a landscape table ends up on its side, or a page fed upside down stays that way. Rotating in your PDF viewer only changes what you see. The file you send still opens sideways for everyone else. Rotating here saves the change into the file.

Rotating only some pages

Mixed documents are common, like a report with a few landscape tables. Leave the pages field empty to rotate everything, or list only the pages that need turning, for example 3,7. The rest stay as they are. If different pages need different directions, rotate one group, download, and run the result again for the next group.

Which direction?

  • Text reads from bottom to top: 90° clockwise.
  • Text reads from top to bottom: 90° counter-clockwise.
  • Page is upside down: 180°.

Before OCR

Text recognition works much better on upright pages. If you're going to run a scan through OCR, rotate it first.

Common examples

  • A phone scan that came out entirely sideways: leave the pages field empty and rotate 90°.
  • A report with a wide table on pages 4 and 5: enter 4,5. If the table reads best in landscape, don't rotate it; only rotate pages that read sideways.
  • A document scanned with half the sheets upside down: enter the upside-down page numbers, such as 2,4,6, and rotate 180°.

Common problems and fixes

  • The page is still slightly crooked: rotation here is in quarter turns (90°, 180°). A sheet scanned a few degrees off needs rescanning; phone scanning apps straighten it automatically.
  • On another computer the file still opens sideways: probably the original was sent, not the file downloaded here. Send the new file.
  • I rotated the wrong way: upload the result and rotate 180°, or start again from the original.

What doesn't change

Rotation doesn't touch the content: text, signatures, quality and links stay as they are. Only the direction the page is shown in changes.
