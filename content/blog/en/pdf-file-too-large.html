"The file exceeds the maximum allowed size." Anyone who has uploaded documents to a government portal, a bank or a job site knows this message. Here's why it happens and what to do about it, from the quick fix to the stubborn cases.

First: why is the PDF so big?

A PDF's size has very little to do with how much text it has. A hundred pages of text created in Word can weigh less than a megabyte. What inflates files is images:

  • Scans. Every scanned page is an image, often at a much higher resolution than needed.
  • Phone photos. A modern phone camera produces images of several megabytes each.
  • Print-resolution graphics. Presentations and brochures exported to PDF with print settings.

So the fix almost always means dealing with the images inside the file.

Fix 1: compress

This is the first thing to try, and it works in most cases. Compress PDF re-encodes the images in the file at a size that still looks sharp on screen, without touching the text.

  1. Start with Medium.
  2. If the site still rejects the file, try High.
  3. Keep Extreme for a particularly strict limit.

After each attempt, open the file, zoom into small text, and make sure it's readable. This matters especially for documents with a signature or an ID, because an unreadable document will be sent back to you.

Fix 2: remove pages you don't need

Sometimes the file includes pages nobody asked for: an explanation page from the bank, blank pages from the scanner, general terms. Removing them with Split PDF is the cleanest way to shrink a file, because nothing loses quality. Enter only the range you need, like 1-3, and download.

Fix 3: split into several files

If the form accepts several files and only limits each one, divide the document into parts. For example, a 30-page medical file into three files of 10 pages. In Split PDF, enter 1-10,11-20,21-30 and you'll get three files.

Fix 4: fix it at the source

If you're creating the file yourself, you can avoid the problem in the first place:

  • On a scanner: 200 or 300 DPI is plenty for documents. There's no need for 600. Scanning in black and white or grayscale, when color isn't needed, makes a big difference.
  • In Word: when saving as PDF, choose the minimum size (publishing online) option, not print quality.
  • On a phone: crop each photo to the edges of the page before converting. Extra margins are extra weight.

What if the site rejects a small file?

Sometimes the message says "size" but the problem is something else:

  • The file is password-protected. Many forms reject encrypted PDFs. Remove the password with Unlock PDF.
  • The file name has special characters. Older systems sometimes struggle with non-English file names, spaces, or symbols like # and &. Rename it using English letters and numbers, like payslip-2026-08.pdf.
  • It isn't really a PDF. An image renamed to .pdf is still an image. Convert it properly with JPG to PDF.

Recommended order

Remove unneeded pages, compress on Medium, check readability, and step up the level if needed. In most cases, the second step already solves it.
