You spent an hour on a CV or a price quote in Word, sent it, and the recipient opened a document where paragraphs jumped, numbers moved and the table broke. The way to prevent this is to send a PDF. Here's how to do it right, especially when the document includes Hebrew or another right-to-left language.

Why Word documents shift on other computers

A Word file isn't a picture of the document, it's a set of building instructions. Every computer rebuilds it using its own fonts, version and settings. When a font is missing, a different one with different widths takes its place, and lines break in new spots. Right-to-left text adds another layer: paragraph direction, tables and numbers that other programs, like Google Docs, LibreOffice or Word on a phone, don't always interpret the same way.

A PDF stores the final position of every character. What you see is what the recipient sees.

How to turn a Word file into a PDF: four ways

1. From Word on a computer

This is the most accurate option when you have Word, because the document is built with exactly your fonts.

  • Windows: File → Save As → choose PDF as the file type → Save. Under Options you can save only some pages, and tick PDF/A compliance, which embeds the fonts and suits documents kept for the long term.
  • Mac: File → Save As, and choose PDF as the file format.

If the file comes out too large to send, the Windows save dialog has a "Minimum size (publishing online)" option. You can also compress the PDF after converting.

2. On a phone

  • Android: open the document, choose Print, and instead of a printer pick Save as PDF.
  • iPhone: open the document, tap Share → Print. On the page preview, pinch outward with two fingers and the document opens as a PDF you can share or save to Files.

Note that showing a Word file on a phone is itself a "rebuild", so right-to-left text isn't always displayed accurately. Check the preview before printing to PDF.

3. In Google Docs

Upload the file to Google Drive, open it in Google Docs, then File → Download → PDF Document. Simple and free, but Google Docs converts the document to its own format first, which can move tables and right-to-left paragraphs. Fine for simple documents.

4. Online, with nothing to install

When you don't have Word, you're on someone else's computer, or you received the file from someone, Word to PDF does it right in the browser. Upload the file and download a PDF. It also works with Excel and PowerPoint, on a computer or a phone.

Before converting: five quick checks

  • Paragraph direction. Make sure right-to-left paragraphs are set as right-to-left, not just aligned right. The difference isn't always visible in Word, but it affects where periods, brackets and numbers land.
  • Numbers inside sentences. A phone number, date or price at the end of a right-to-left sentence tends to jump. Reread those lines.
  • Tables. A Hebrew table should be set right-to-left so the first column is on the right.
  • Fonts. In an online conversion, common fonts are usually replaced with a similar font of the same width, so lines don't move. A special font you downloaded may look different. If the font matters, for an invitation or a logo, export from Word.
  • File name. cv-dana-levi.pdf, not Document1.pdf.

Common right-to-left problems, and how to fix them in Word

  • A period or bracket on the wrong side of the line. The paragraph is aligned right but its direction is left-to-right. Select it and click Right-to-Left Text Direction on the Home tab.
  • The table is reversed, with the first column on the left. Right-click the table → Table Properties → on the Table tab set the direction to Right-to-left.
  • A phone number or price "jumps" at the end of a sentence. If fixing the paragraph direction didn't help, rephrase so the number isn't the last word, or add a word after it.
  • The recipient sees a different font. On Windows: File → Options → Save → Embed fonts in the file. That affects the Word file itself; saving as PDF solves it either way.
  • A blank page at the end of the PDF. There's usually an empty paragraph or page break at the end of the document. Delete it in Word and convert again, or remove the page with Split PDF.

After converting

Open the PDF and go through it as the recipient would: are all pages there, are the margins right, are tables intact? If it's sensitive, like a quote with prices or a document with personal details, add a password or a watermark.
