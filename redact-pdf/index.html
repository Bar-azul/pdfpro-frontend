Redact a PDF

Black out ID numbers, names or account details before you share a document. The hidden text is removed from the file, not just covered.

    Separate several items with commas. Every occurrence in the file is blacked out.

    
    
    
    
    Files are processed on our server and deleted automatically after one hour.
    
  
    

  
    
    
    Why redaction matters
    

    Documents often carry more personal information than the recipient needs. A payslip shows your ID number and bank account. A bank statement lists every transaction. A medical summary includes details unrelated to the claim. Redacting lets you share the document while hiding the parts that aren't anyone else's business.
    

    Covering is not redacting
    

    Drawing a black rectangle over text in a PDF editor usually only hides it visually. The text underneath is still in the file, and anyone can copy it out or find it by searching. This tool removes the text itself and replaces it with a black box, so the hidden information is actually gone from the file.
    

    How to use it well
    

      

    • Type the text exactly as it appears in the document, including dashes and spaces. An ID number written as 123456782 won't match 12345678-2.
      • 

    • List several items at once, separated by commas.
      • 

    • After downloading, open the file and search for the hidden text to confirm it's gone.
      • 

    

    Scanned documents
    

    A scan is an image, so there's no text to find. Run it through OCR with the Searchable PDF output first, then redact the result.
    

    
    How it works
    
    
    1. Choose your PDF
      Drop the file into the box above.
    2. Type what to hide
      An ID number, a name, an address. Separate items with commas.
    3. Download
      Every occurrence is blacked out and removed.
    
    
    Frequently asked questions
    
    
    Is the text really removed, or just covered?
    Removed. The black box replaces the text in the file itself, so it can't be copied or found by searching.
    It didn't find my text.
    The text has to match exactly as it appears in the PDF, including spaces and dashes. Scanned documents contain images instead of text, so run them through OCR first.
    Does it work with Hebrew?
    Yes, as long as the PDF contains real Hebrew text, which is the case for most documents created on a computer.
