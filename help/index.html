Help Center

Answers to the questions we get most often.

Using the tools

Do I need an account?

No. Open a tool, add your file, and download the result.

What's the maximum file size?

100 MB per file. Merge accepts up to 20 files at once.

Is there a usage limit?

Yes, a number of files per hour for each tool. The exact numbers are on the pricing page.

Why did the first file take so long?

When nobody has used the site for a while, the server goes to sleep and needs up to a minute to start. After that, files are processed in seconds.

Hebrew and RTL

My Hebrew text came out reversed. What happened?

This usually happens with other converters that don't handle right-to-left text. If it happens with PDFPro, please tell us which tool you used. The RTL guide explains the cause.

Can I OCR a document that mixes Hebrew and English?

Yes. In OCR, choose Hebrew + English.

Privacy

What happens to my files?

They're processed on our server and deleted automatically after one hour. We don't read or keep them. See the privacy policy.

Troubleshooting

"The file has expired" when downloading

Results are kept for one hour. Process the file again to get a new copy.

"Hourly limit reached"

Wait an hour, or use a different tool in the meantime.
