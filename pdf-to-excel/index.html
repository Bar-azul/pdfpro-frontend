PDF to Excel converter

Pull the tables out of a PDF and into an Excel spreadsheet, ready to sort, filter and calculate.

    
    
    
    
    Files are processed on our server and deleted automatically after one hour.
    
  
    

  
    
    
    When you need PDF to Excel
    

    Numbers locked inside a PDF are hard to work with. Converting to Excel lets you sort a bank statement by amount, total up expenses from a credit card report, compare supplier price lists, or pull figures from a financial report into your own calculations.
    

    Free, online, nothing to install
    

    There's no software to download and no account to create. The conversion runs in your browser on any computer or phone, and you download a standard .xlsx spreadsheet that opens in Excel, Google Sheets, LibreOffice Calc or Numbers.
    

    How the tables are extracted
    

    The converter looks for tables on each page and places each one on its own sheet, named after the page it came from. Nothing gets merged by mistake, and you can combine sheets yourself if you need one long table.
    

    Getting the best result
    

      

    • Use a PDF that was generated by software, like a statement downloaded from online banking. Scans contain images, not numbers, so run them through OCR first.
      • 

    • Check number formats. Amounts with currency symbols or thousands separators may import as text. In Excel, select the column and use Text to Columns, or remove the symbols with Find and Replace.
      • 

    • Tables that continue across pages arrive as one sheet per page. Copy them under each other to rebuild the full table.
      • 

    

    Only need part of the file?
    

    For a long report where only a few pages have tables, pull those pages out first with Split PDF. The result is cleaner and faster.
    

    
    How it works
    
    
    1. Choose your PDF
      Pick a PDF that contains tables, like a bank statement, price list or report.
    2. Extract tables
      Each table is detected and placed on its own sheet, named by page number.
    3. Download
      Open the .xlsx file in Excel, Google Sheets or LibreOffice Calc.
    
    
    Frequently asked questions
    
    
    What if the PDF has several tables?
    Every table goes to a separate sheet, labeled with the page it came from, so nothing gets merged by mistake.
    Does it work with scanned PDFs?
    Table extraction needs real text in the PDF. For a scan, run it through the OCR tool first.
    Is it free?
    Yes, with an hourly limit per tool and no sign-up.
    Do I need to download or install anything?
    No. The converter runs in your browser, on any computer or phone. You only download the finished Excel file.
    Can I open the result in Google Sheets?
    Yes. Upload the .xlsx file to Google Drive and open it with Google Sheets, or use File, Import in an existing sheet.
    What's the maximum file size?
    Up to 100 MB per file.
