PDF to Excel converter

Pull the tables out of a PDF and into an Excel spreadsheet, ready to sort, filter and calculate.

    
    
    
    
    Files are processed on our server and deleted automatically after one hour.
    
  
    

  
    
    
    How it works
    
    
    1. Choose your PDF
      Pick a PDF that contains tables, like a bank statement, price list or report.
    2. Extract tables
      Each table is detected and placed on its own sheet, named by page number.
    3. Download
      Open the .xlsx file in Excel, Google Sheets or LibreOffice Calc.
    
    
    Frequently asked questions
    
    
    What if the PDF has several tables?
    Every table goes to a separate sheet, labeled with the page it came from, so nothing gets merged by mistake.
    Does it work with scanned PDFs?
    Table extraction needs real text in the PDF. For a scan, run it through the OCR tool first.
    Is it free?
    Yes, with an hourly limit per tool and no sign-up.
    What's the maximum file size?
    Up to 100 MB per file.
