PDF to PowerPoint

Turn a PDF into a PowerPoint file with one slide per page, so you can present it, reorder it and add your own slides.

    
    
    
    
    Files are processed on our server and deleted automatically after one hour.
    
  
    

  
    
    
    When you need PDF to PowerPoint
    

    Someone sent you slides as a PDF and you need to present them, add a few slides of your own, or reorder them. Converting to PowerPoint puts each page on its own slide, so you can present in full screen, drag slides around and mix them into your own deck.
    

    How the conversion works
    

    Each page is placed on a slide as a high-quality image. That's why the result looks exactly like the PDF, including fonts, charts and Hebrew text, with nothing shifting. The trade-off is that the text on those slides can't be edited directly. You can still add text boxes, shapes and notes on top, or add new slides between them.
    

    Need editable text?
    

    If you need to change the wording, use PDF to Word to get editable text, then paste it into your slides.
    

    Keeping the file size down
    

    Standard quality is enough for a projector or a video call. Very high is only worth it for printing or very large screens, and makes a much bigger file.
    

    
    How it works
    
    
    1. Choose your PDF
      Slides exported as PDF convert best.
    2. Pick the quality
      Standard is enough for a projector or a screen share.
    3. Download the PPTX
      Open it in PowerPoint, Google Slides or Keynote.
    
    
    Frequently asked questions
    
    
    Can I edit the text on the slides?
    Each page is placed on its slide as a high-quality image, so the layout looks exactly like the PDF, but the text can't be edited directly. To edit the text, use PDF to Word.
    Why is the file large?
    Every slide is an image. Choose Standard quality for a smaller file.
    Will Hebrew slides look right?
    Yes. Because each page is copied as an image, Hebrew text and layout look exactly as in the PDF.
