How to Convert a PDF Table to Excel (Without Retyping It)

October 9, 2026

Copying a table out of a PDF usually ends badly: paste it into Excel and every row lands in a single cell, numbers turn into text, and columns slide out of place. Converting the file instead keeps rows and columns where they belong. Here's how to do it, and what to do about the cases that don't convert cleanly.

First, check what kind of PDF you have

Open the PDF and try to select a word in the table with your mouse.

  • The text highlights: the PDF contains real text. This is the usual case for files downloaded from a website, exported from accounting software, or saved from Word or Excel. These convert accurately.
  • Nothing highlights, or the whole page highlights as one block: the page is an image, usually a scan or a phone photo. Skip to the section on scanned tables below.

Converting a PDF table to Excel

  1. If the PDF asks for a password when you open it, remove it first with Unlock PDF.
  2. Open PDF to Excel and upload the file.
  3. Download the .xlsx file and open it in Excel, Google Sheets or LibreOffice Calc.

Every table goes to its own sheet, named after the page it came from ("Page 1", "Page 2 table 2" and so on), so two tables on the same page never get mixed together. Amounts such as 12,450.00 arrive as real numbers you can sum, including negative amounts written with the minus sign after the number, as many bank statements do. Long numbers like account or ID numbers, and numbers that start with a zero, are kept as text so Excel doesn't round them or drop the zero.

Which tables convert best

Tables drawn with lines between the cells, like most statements, invoices and reports, convert cell by cell. A "table" that is really just text lined up with spaces has no cell borders to detect, so it comes out as one line of text per row in column A. That's still faster than retyping: select column A, then use Data → Text to Columns and split by spaces or by fixed width.

Tidying up in Excel

  • One table across several pages: you'll get one sheet per page. Copy them under each other into one sheet and delete the repeated header rows.
  • Merged header cells: a header that spans two columns in the PDF may land in only one of them. Fix the header row by hand. It takes a minute.
  • Dates: if sorting by date gives a strange order, Excel is treating them as text. Select the column and use Text to Columns with the date format set (for example DMY).
  • Hebrew or Arabic tables: the text comes out in the right order, but the sheet itself is left-to-right. To view it right-to-left, use Page Layout → Sheet Right-to-Left in Excel.

Scanned tables

A scan is a picture of a table, so there are no cells to extract. Run it through OCR first and choose Searchable PDF, then convert that file to Excel. The result is one line of text per row, which you split into columns with Text to Columns as described above. Check the numbers against the original: OCR can misread a digit, especially on a blurry photo.

Is it safe to upload?

Statements and invoices are sensitive. Files are processed on our server and deleted automatically after one hour. If you only need part of a long document, take out the relevant pages first with Split PDF. For bank and credit card statements specifically, see the guide to turning a bank statement into a spreadsheet.
