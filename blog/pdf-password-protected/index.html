Password-Protected PDF: What to Do When You've Lost the Password

July 5, 2026

A payslip, bank statement or pension report arrives with a password, and now you need to open it, forward it or combine it with other documents. This guide covers where to find the password, how to remove it once you know it, and what your options are if it's really lost.

First: which kind of password is it

  • An open password: the file won't open at all without it. Most personal documents, such as payslips, statements and reports, arrive like this.
  • Usage restrictions: the file opens normally, but you can't print it, copy text or edit it. Whoever created the file set that. If you need to print or copy, the simple route is to ask them for an unrestricted version.

Where to find the password

  • Israeli payslips: usually your ID number, sometimes without the check digit (the last digit). If that fails, payroll will know.
  • Banks, insurers and pension funds: the password is usually in the email that came with the file or in a separate message. Often it's your ID number or part of it.
  • A file you protected yourself: check your password manager or browser, and look for an unprotected original in Google Drive, OneDrive or a backup.

When typing a password, watch two things: capital letters matter, and the keyboard sometimes switches language without you noticing. If a password you're sure of is "wrong", type it in a text editor and paste it.

How to remove a password you know

  1. Open Unlock PDF and choose the file.
  2. Type the password.
  3. Download the file. Pages, text and quality stay exactly the same; only the encryption is removed.

Why remove it at all? Because an encrypted file can't be merged, compressed or converted. If a bank wants your last three payslips in one file, unlock each one and then merge them. There's a full guide for that.

The password really is lost

Our tool doesn't crack passwords; it only removes protection you can already open. That isn't just a technical point: with properly encrypted documents, guessing a password can take years, and sites promising to "unlock any PDF" are unreliable at best and a source of malware at worst. The real options:

  • Ask the sender for a new copy or the password. Payroll, banks and insurance agents reissue documents easily.
  • Download it again from your account. Many documents, such as payslips, statements and annual reports, are also available in the provider's website or app, sometimes without a password.
  • Look for an earlier version in backups, if it's a file you created.

After you've opened it

A file without a password is easier to send, and also easier to end up with the wrong person. If you're forwarding it, you can add protection again with a new password only the recipient knows using Protect PDF, and send the password separately, for example by text message rather than in the same email.
