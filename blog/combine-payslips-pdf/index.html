How to Combine Password-Protected Payslips into One PDF

September 26, 2026

The bank asked for your recent payslips, and you have several separate PDFs, each locked with a password. This guide shows how to turn them into one tidy file that any upload form will accept.

Why one file?

Mortgage, loan and rental applications almost always come with a list of documents: payslips, bank statements, certificates. Some organizations let you upload each document separately, but many forms allow only one file per section or limit how many files you can attach. Even when you're emailing a mortgage broker, one file ordered by month saves them time and saves you follow-up questions.

The problem: password-protected payslips

Many payroll systems email payslips as locked PDFs, often using the employee's ID number as the password. That makes sense for security, but it causes two problems:

  • Merge tools can't open an encrypted file, so merging fails or skips it.
  • Some upload forms reject encrypted files, sometimes with a generic error that doesn't explain why.

So the right order is: remove the password first, then merge.

Step 1: remove the password from each payslip

  1. Open Unlock PDF.
  2. Upload one payslip and type the password you normally use to open it.
  3. Download the unlocked copy, and repeat for each payslip.

If it says the password is wrong, check that your keyboard hasn't switched language, and try with and without any check digit. If it still fails, your payroll department can tell you the password.

Step 2: merge into one file

  1. Open Merge PDF.
  2. Add all the unlocked payslips.
  3. Put them in month order. Most recent first is the most common, but if the organization specifies an order, follow it.
  4. Merge and download.

Step 3: check the size

Payslips generated by payroll software are usually small, but if some are photos or scans, the combined file can exceed the upload limit. Run it through Compress PDF on Medium, and open the result to make sure the amounts are still readable.

Give the file a clear name

A name like payslips-dana-levi-2026-06-to-08.pdf helps a clerk or broker find it quickly, especially when they're handling dozens of files. Avoid names like scan001.pdf.

What about security?

You removed the passwords, so the combined file opens for anyone who receives it. If you're sending it by email rather than through the bank's secure system, consider locking it again with Password protect PDF and sending the password in a separate message. If the payslips show details the recipient doesn't need, like the bank account your salary goes into, you can hide them with Redact PDF. Just check first that the organization doesn't need that exact detail.

In short

Unlock each payslip, merge them in month order, check the size, and give the file a clear name. The whole process takes a few minutes and needs no software installed.
