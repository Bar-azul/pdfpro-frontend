Split PDF

Cut a long PDF into smaller files, or pull out just the pages you need.

    Separate ranges with commas, e.g. 1-3,4-6 or just 5 for a single page.

    
    
    
    
    Files are processed on our server and deleted automatically after one hour.
    
  
    

  
    
    
    
    How it works
    
    
    1. Choose your PDF
      Drop the file into the box above.
    2. Enter page ranges
      Write the ranges you want, like 1-3,4-6. Each range becomes a separate file.
    3. Download
      Save each part.
    
    
    Frequently asked questions
    
    
    How do I extract one page?
    Type just that page number, for example 5.
    Can I get several separate parts?
    Yes. 1-2,3-5,6-10 gives you three PDFs.
    Does splitting change the quality?
    No. Pages are copied exactly.
    What's the maximum file size?
    Up to 100 MB per file.
